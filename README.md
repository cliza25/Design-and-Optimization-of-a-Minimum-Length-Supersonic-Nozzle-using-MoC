# Design-and-Optimization-of-a-Minimum-Length-Supersonic-Nozzle-using-MoC
Designed a 2D minimum-length supersonic nozzle for (M_e=3.0) using a 20-characteristic-line MATLAB MoC implementation, achieving uniform axial exit flow with a 140.12 mm nozzle length, 79.07 mm exit height, and 27.88° maximum wall angle.
